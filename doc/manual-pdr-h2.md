# Running a PDR + H2 model

This manual has become the tutorial of the documentation site:

**https://mocassin-pdr.readthedocs.io/en/latest/tutorials/dust-gas-pdr.html**

It runs `benchmarks/test_Problem` as a complete dust + gas + PDR + H2 model with release
`pdr-coupling-v2.0.1`, from the inputs in `examples/tutorial/`, and shows how to check the
run, slice the model, map its H2 and CO lines and continue it with a warm start. The text
that stood here until 2026-10-24 is in the repository's history (DEVLOG D-440).
